# Lhasa Clothing Store 👕🛍️

A modern online clothing store website developed using PHP, MySQL, HTML, CSS, and JavaScript.

This project allows users to browse fashion products, explore categories, register/login, and view special fashion offers. It also includes an Admin Panel for product management.

---

# 🚀 Features

- 🏠 Home Page with Fashion Collection Showcase
- 👕 Product Listing Page
- 📂 Category-wise Product Filtering
- 🎁 Offers & Discount Section
- 🔐 User Registration & Login System
- 👨‍💼 Admin Login & Product Management
- ➕ Add New Products with Image Upload
- 📱 Fully Responsive Design
- 📧 Contact Page

---

# 🛠️ Technologies Used

- Frontend: HTML5, CSS3, JavaScript
- Backend: PHP
- Database: MySQL
- Styling: Custom CSS
- Validation: JavaScript Form Validation

# 💻 Installation Guide

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/lhasa-clothing-store.git
```

---

## 2️⃣ Move Project to XAMPP

Copy the project folder into:

```bash
htdocs/
```

Example:

```bash
C:/xampp/htdocs/Lhasa-Clothing-Store
```

---

## 3️⃣ Start Apache & MySQL

Open XAMPP Control Panel and start:

- Apache
- MySQL

---

## 4️⃣ Create Database

Open:

```bash
http://localhost/phpmyadmin
```

Create a database named:

```sql
shopping
```

Import your SQL database file.

---

## 5️⃣ Run the Project

Open browser:

```bash
http://localhost/Lhasa-Clothing-Store
```
